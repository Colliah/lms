# Server Actions API Documentation

Server Actions provide the API layer for the LMS, handling authentication, input validation, and error transformation.

## Architecture

### Layer Responsibilities

```
┌─────────────────────────────────────┐
│         UI Components               │
│  (Client Components & Pages)        │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│       Server Actions                │
│  • Authentication Check             │
│  • Input Validation (Future: Zod)  │
│  • Call Service Functions           │
│  • Transform Errors                 │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│       Service Layer                 │
│  • Business Logic                   │
│  • Database Operations              │
│  • Complex Calculations             │
└─────────────────────────────────────┘
```

---

## Standard Action Pattern

All server actions follow this consistent pattern:

```typescript
"use server";

import { auth } from "@/lib/auth";
import { headers } from "next/headers";
import { serviceFunction } from "@/services/module";

export async function actionName(data: {
  param1: string;
  param2: number;
}) {
  try {
    // 1. Authentication Check
    const session = await auth.api.getSession({
      headers: await headers(),
    });

    if (!session) {
      return { success: false, error: "Unauthorized" };
    }

    // 2. Call Service Layer
    const result = await serviceFunction({
      userId: session.user.id,
      ...data,
    });

    // 3. Return Success Response
    return { success: true, data: result };
    
  } catch (error) {
    // 4. Error Handling
    console.error("actionName error:", error);
    return {
      success: false,
      error: error instanceof Error ? error.message : "Operation failed"
    };
  }
}
```

---

## Response Format

All actions return a discriminated union type:

```typescript
type ActionResponse<T> =
  | { success: true; data: T }
  | { success: false; error: string };
```

**Success Response**:
```typescript
{
  success: true,
  data: {
    // Type-safe data matching service function return
  }
}
```

**Error Response**:
```typescript
{
  success: false,
  error: "Human-readable error message"
}
```

## Error Handling Best Practices

### 1. Catch Service Errors
```typescript
try {
  const result = await serviceFunction(params);
  return { success: true, data: result };
} catch (error) {
  return {
    success: false,
    error: error instanceof Error ? error.message : "Unknown error"
  };
}
```

### 2. Log Errors for Debugging
```typescript
catch (error) {
  console.error("actionName error:", error);
  return { success: false, error: "User-friendly message" };
}
```

### 3. Type-Safe Error Messages
```typescript
// Bad
return { success: false, error: error };

// Good
return {
  success: false,
  error: error instanceof Error ? error.message : "Operation failed"
};
```

## Client-Side Usage Patterns

### In Server Components
```typescript
// Direct call (no state management needed)
export default async function Page() {
  const result = await fetchDataAction();
  
  if (!result.success) {
    return <Error message={result.error} />;
  }
  
  return <Display data={result.data} />;
}
```

### In Client Components
```typescript
"use client";

import { useState } from "react";
import { submitAction } from "@/app/actions/module";

export default function Component() {
  const [isLoading, setIsLoading] = useState(false);
  
  async function handleSubmit() {
    setIsLoading(true);
    const result = await submitAction(data);
    
    if (result.success) {
      // Handle success
    } else {
      // Show error: result.error
    }
    setIsLoading(false);
  }
  
  return <button onClick={handleSubmit}>Submit</button>;
}
```

### With React Transition
```typescript
"use client";

import { useTransition } from "react";

export default function Component() {
  const [isPending, startTransition] = useTransition();
  
  function handleAction() {
    startTransition(async () => {
      const result = await actionName();
      // Handle result
    });
  }
}
```

const schema = z.object({
  wordId: z.string().cuid(),
  quality: z.nativeEnum(ReviewQuality),
});

export async function submitReview(data: unknown) {
  const validated = schema.parse(data);

}

### Add Rate Limiting
```typescript
import { rateLimit } from "@/lib/rate-limit";

export async function actionName(data: Params) {
  const { success } = await rateLimit.check(userId);
  if (!success) {
    return { success: false, error: "Too many requests" };
  }
  // Continue...
}
```

### Add Caching
```typescript
import { unstable_cache } from "next/cache";

export const getCachedData = unstable_cache(
  async (userId: string) => {
    return await fetchData(userId);
  },
  ["cache-key"],
  { revalidate: 3600 }
);
```
