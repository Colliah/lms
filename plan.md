## 3. Feature Modules

### Phase 1: MVP (Months 1-2)

### 3.1 User Authentication & Onboarding

- Email/password authentication
- Social login (Google, optional)
- Onboarding flow:
    - Current English level assessment
    - Learning goals (conversation, business, travel, academic)
    - Interests/topics
    - Daily study time commitment
    - Preferred learning style

### 3.2 Vocabulary Module

- **Features**:
    - Flashcard system with spaced repetition (SM-2 algorithm)
    - Word categories (common, business, travel, academic)
    - Audio pronunciation
    - Example sentences
    - Visual images for context
    - Multiple review modes (recognition, recall, spelling)
- **Data Structure**:
    - 2000+ essential English words
    - Organized by difficulty (A1, A2, B1, B2)
    - Tagged by topic/category

### 3.3 Progress Tracking

- Dashboard with key metrics:
    - Daily streak
    - Words mastered
    - Exercises completed
    - Study time
    - Level progress bar
- Visual charts (weekly/monthly progress)
- Achievement badges

### 3.4 Basic Grammar Exercises

- Exercise types:
    - Multiple choice
    - Fill in the blank
    - Sentence correction
    - Match the pattern
- Grammar topics:
    - Present/past/future tenses
    - Articles (a, an, the)
    - Prepositions
    - Basic sentence structure
- Instant feedback with explanations

### Phase 2: Enhanced Learning (Months 3-4)

### 3.5 Reading Module

- Graded reading passages (A1-B2)
- Topics based on user interests
- Interactive features:
    - Click words for definitions
    - Audio narration
    - Highlight and save vocabulary
- Comprehension questions
- Reading speed tracking

### 3.6 Writing Module

- Guided writing exercises:
    - Sentence construction
    - Paragraph writing
    - Email/letter templates
    - Descriptive writing
- AI-powered feedback:
    - Grammar corrections
    - Vocabulary suggestions
    - Structure improvements
- Writing prompts based on level

### 3.7 Speaking Module

- Pronunciation practice:
    - Word pronunciation
    - Sentence repetition
    - Tongue twisters
- Speech recognition scoring
- Common conversation scenarios:
    - Introductions
    - Ordering food
    - Asking directions
    - Phone conversations
- Record and compare with native speakers

### Phase 3: Personalization & Community (Months 5-6)

### 3.8 Adaptive Learning Path

- AI-powered personalized curriculum
- Difficulty adjustment based on performance
- Focus on weak areas
- Recommended daily lessons
- Alternative learning paths

### 3.9 Enhanced Progress System

- Detailed analytics:
    - Strengths and weaknesses
    - Time spent per module
    - Accuracy rates
    - Learning velocity
- Predictive level assessment
- Goal setting and tracking

### 3.10 Community Features (Optional)

- Study groups
- Language exchange partners
- Discussion forums
- User-generated content
