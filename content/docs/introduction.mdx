# English Learning Management System

## Overview

The English Learning Management System (LMS) is a comprehensive web-based platform designed to help learners master English through interactive lessons, spaced repetition, and personalized progress tracking.

## Key Features

### 🎯 Adaptive Learning
- Proficiency-based content (A1-C2 CEFR levels)
- Personalized learning paths
- Real-time progress adaptation

### 📚 Five Learning Modules

#### 1. Vocabulary
- **SM-2 Spaced Repetition**: Scientifically-proven algorithm for optimal retention
- Interactive flashcards with audio pronunciation
- Example sentences and visual aids
- Daily review scheduling based on performance

#### 2. Grammar
- Topic-based exercises (Present Simple, Past Perfect, etc.)
- Multiple question types (Multiple Choice, Fill-in-the-Blank)
- Instant feedback with explanations
- Progressive difficulty levels

#### 3. Reading Comprehension
- Graded passages appropriate to user level
- Comprehension questions
- Reading speed tracking (Words Per Minute)
- Vocabulary highlighting and definitions

#### 4. Writing Practice
- Guided prompts across multiple formats (Essay, Email, Story)
- Word count validation
- AI-powered feedback (grammar, vocabulary, structure)
- Portfolio of past submissions

#### 5. Speaking & Pronunciation
- Target phrase exercises
- Native speaker audio references
- Recording and playback
- Pronunciation scoring and feedback

### 📊 Progress Tracking

- **Daily Streaks**: Maintain motivation with streak counters and freeze features
- **Achievements**: Unlock badges across all learning modules
- **Analytics Dashboard**: Visualize progress with charts and statistics
- **Weekly Reports**: Track study time and performance trends

### 🎮 Gamification

- Streak-based rewards
- Achievement system
- Progress milestones
- Daily goals and challenges

## Learning Algorithm: SM-2

The vocabulary module uses the **SM-2 (SuperMemo 2)** spaced repetition algorithm, which:

1. **Adapts to Individual Performance**: Easiness Factor adjusts based on recall quality
2. **Optimizes Review Intervals**: Schedules reviews at optimal times for retention
3. **Prevents Cramming**: Spaces reviews for long-term memory formation
4. **Tracks Mastery**: Identifies when a word is truly learned

### Quality Ratings
- **Again**: Forgot completely → Reset to 1-day interval
- **Hard**: Struggled → Short interval (1-3 days)
- **Good**: Remembered well → Moderate interval (3-7 days)  
- **Easy**: Perfect recall → Long interval (7+ days)
